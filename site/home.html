An unofficial reference for jBC, the Basic-like programming language of the jBASE multi-value database, used in Temenos TAFC and TAFJ and in T24. It covers syntax, compilation, environment variables, data files, system variables and every function and statement, with notes on where TAFJ behaves differently from TAFC. This is not a Temenos document.

Start with the preface, read the whole guide on one page, browse the grammar diagrams or try jBC in the online playground. The experimental jbcc compiler translates jBC to C.
