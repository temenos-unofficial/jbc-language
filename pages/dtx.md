# DTX

The DTX function will return the hexadecimal representation of a numeric
expression.

## COMMAND SYNTAX

    DTX(expression)

## SYNTAX ELEMENTS

expression must evaluate to a decimal numeric value or a runtime error
will occur.

## NOTES

See also: [XTD](https://jbc-lang.org/pages/xtd.md).

## EXAMPLES

    Decimal = 254
    CRT DTX(Decimal)

displays FE
