# Built-in functions and other expression calls

Look up a spelling here, then use the token or function class in the `resultant` productions of [jbc.y](jbc.y). The table includes cursor positioning and the explicit CALLC expression. For external declarations see [JBC.h functions](header-functions.md).

`FUNC_PARM0` through `FUNC_PARM3` are lexer dispatch classes. The digit is the nominal argument count. Dedicated tokens have their own productions, including optional arguments and writable destinations. A dash denotes no matching guide chapter. “Guide” denotes a documented call without a matching expression token in this table.
